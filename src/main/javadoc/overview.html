OpenRoots IoT Backend API

This API provides project, device, and telemetry management for the OpenRoots IoT platform.

Application areas

  • Devices: register, list, retrieve, and remove devices and sensors.
  • Telemetry: ingest and query device measurements.
  • Projects: manage projects and their members.
  • Messaging: consume telemetry delivered through MQTT.

HTTP endpoint contracts are defined in OpenAPI-generated interfaces and the project specification in docs/openapi.yaml.
