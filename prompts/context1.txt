===========================================================
SUPPORTED DEVICE UPLINK TYPES (v1)
===========================================================

+----------------+-------------------------+----------------------------+-----------------------------------------------+---------------------------+
| Uplink         | Transport               | Typical Devices            | Best For                                      | Spring Entry Point        |
+----------------+-------------------------+----------------------------+-----------------------------------------------+---------------------------+
| HTTPS (REST)   | HTTP / HTTPS            | ESP32, Raspberry Pi,       | Registration, telemetry, firmware,            | REST Controller           |
|                |                         | Linux SBCs, Cellular       | configuration, image uploads                  |                           |
+----------------+-------------------------+----------------------------+-----------------------------------------------+---------------------------+
| MQTT           | MQTT over TCP / TLS     | ESP32, STM32, Raspberry Pi | Continuous telemetry, commands,               | MQTT Listener             |
|                |                         |                            | device status                                 |                           |
+----------------+-------------------------+----------------------------+-----------------------------------------------+---------------------------+
| LoRaWAN (v2)   | LoRa → Network Server   | Remote battery sensors     | Long-range telemetry                          | MQTT Listener / REST      |
|                | → MQTT / HTTP           |                            |                                               | Controller                |
+----------------+-------------------------+----------------------------+-----------------------------------------------+---------------------------+
