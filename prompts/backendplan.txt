===========================================================
COMPLETE BACKEND DEVELOPMENT ROADMAP
(Open-Source Self-Hosted IoT Platform)
===========================================================

Phase 1 ─ High-Level Architecture ✅
-----------------------------------
Goal:
    Define how data enters, flows through, and leaves the system.

Topics:
    • Spring Boot
    • REST Controllers
    • MQTT Listeners
    • MQTT Publishers
    • WebSockets
    • PostgreSQL
    • Docker
    • Package Structure
    • Overall System Architecture


Phase 2 ─ Domain Modeling
--------------------------
Goal:
    Define the "things" that exist in the platform.

Questions:
    • What is a User?
    • What is a Project?
    • What is a Device?
    • What is a Gateway?
    • What is Telemetry?
    • What is a Sensor?
    • What is Firmware?
    • What is an Alert?
    • What is a Command?
    • What is a Notification?

Deliverables:
    • Entity list
    • Relationships
    • Business rules


Phase 3 ─ Database Design
-------------------------
Goal:
    Convert the domain model into PostgreSQL tables.

Topics:
    • Tables
    • Columns
    • Primary Keys
    • Foreign Keys
    • Constraints
    • Indexes
    • Normalization
    • Entity Relationships
    • Migrations
    • Partitioning (later)

Deliverables:
    • ER Diagram
    • SQL Schema
    • Spring Entities


Phase 4 ─ Authentication & Authorization
----------------------------------------
Goal:
    Secure users and devices.

Users:
    • JWT Authentication
    • Roles
    • Permissions

Devices:
    • Device Secret
    • API Keys
    • Certificates (future)

Questions:
    • Who owns a device?
    • Can projects be shared?
    • Can multiple users access the same device?


Phase 5 ─ REST API Design
-------------------------
Goal:
    Design clean REST endpoints.

Examples:
    POST   /auth/login
    POST   /devices
    GET    /devices
    GET    /devices/{id}
    POST   /telemetry
    GET    /telemetry
    POST   /commands
    GET    /alerts

Topics:
    • DTOs
    • Validation
    • Pagination
    • Filtering
    • API Versioning

Phase 8 ─ Device Lifecycle
--------------------------
Goal:
    Manage devices from birth to retirement.

Lifecycle:
    Register
        ↓
    Provision
        ↓
    Authenticate
        ↓
    Send Telemetry
        ↓
    Receive Commands
        ↓
    Firmware Update
        ↓
    Decommission
